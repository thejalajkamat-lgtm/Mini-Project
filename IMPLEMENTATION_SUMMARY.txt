🔧 KEY TECHNICAL DETAILS:

FileReader API Usage:
──────────────────
const reader = new FileReader();
reader.onload = function(event) {
    const base64String = event.target.result.split(',')[1];
    // Now have base64 string to store
};
reader.readAsDataURL(noteFile);


Base64 Encoding/Decoding:
──────────────────────
ENCODE (upload):
    FileReader.readAsDataURL() → "data:application/pdf;base64,JVBERi..."
    Extract: split(',')[1] → "JVBERi..."
    Store in localStorage

DECODE (download):
    atob(base64String) → binary string
    Create Uint8Array from string → byte array
    new Blob([byteArray], {type: mimeType}) → file blob


Object URL Creation:
─────────────────
const url = URL.createObjectURL(blob);
// Returns: blob:http://localhost:3000/a1b2c3d4-e5f6-...

// Download trigger:
link.href = url;
link.download = filename;
link.click();

// Cleanup:
URL.revokeObjectURL(url);


Storage Persistence:
──────────────────
localStorage.setItem('noteshub_notes', JSON.stringify(notes));
// Notes with fileData (base64) are stored as JSON
// Data persists across browser sessions

⚠️  STORAGE LIMITS & CONSIDERATIONS:

localStorage Capacity:
  • Desktop: 5-10 MB (varies by browser)
  • Mobile: 5-10 MB
  • Base64 adds ~33% overhead

File Size Limits:
  • Per file: 10 MB max (enforced in code)
  • Recommended: 100 KB - 2 MB
  • Total storage: 5-10 MB

Base64 Size Example:
  • 1 MB PDF → ~1.33 MB in base64
  • 5 MB file → ~6.65 MB in base64

Optimal Use Cases:
  ✓ Study notes (100-500 KB)
  ✓ Study guides (1-3 MB)
  ✓ Past papers (2-5 MB)
  ✗ Large videos (not recommended)
  ✗ High-resolution images (compress first)
