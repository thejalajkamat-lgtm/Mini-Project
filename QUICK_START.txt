💾 STORAGE INFORMATION

localStorage Capacity:
  • Total: 5-10 MB per domain
  • Per file: 10 MB max
  • Recommended: 100 KB - 2 MB each

File Size Estimation:
  • 500 KB file → ~665 KB stored (33% overhead)
  • 1 MB file → ~1.33 MB stored
  • 5 MB file → ~6.65 MB stored

Recommended Setup:
  ✓ 5 notes at 1 MB each = ~6.65 MB total ✓
  ✗ 5 notes at 2 MB each = ~13.3 MB (too much) ✗

❓ FAQ

Q: Can I access files after closing browser?
A: Yes! Files persist in localStorage

Q: What if I clear browser history?
A: Files in localStorage might be deleted (depends on settings)

Q: How much can I store?
A: ~5-10 MB total, optimal with 3-5 typical notes

Q: Can I share files?
A: Not in this version (would need server/cloud)

Q: Are files encrypted?
A: No, they're stored as base64 in localStorage

Q: Can I upload folders?
A: No, only individual files

Q: What's the file size limit?
A: 10 MB per file, ~5-10 MB total storage

Q: Will files sync across devices?
A: No, only stored locally in this browser

🛠️ TROUBLESHOOTING

Problem: Download doesn't work
Solution:
  1. Check browser console (F12)
  2. Verify file was uploaded (check Browse Notes)
  3. Try test suite first
  4. Check browser storage (DevTools → Application)

Problem: File too large
Solution:
  1. Compress file before upload
  2. Maximum 10 MB per file
  3. Total storage ~5-10 MB
  4. Recommended: 1-2 MB per file

Problem: File corrupted after download
Solution:
  1. Run integrity test in test suite
  2. Verify original file wasn't corrupted
  3. Check MIME type is correct
  4. Try different file type

Problem: Storage full
Solution:
  1. Delete old notes
  2. Use "Clear All Notes" in test suite
  3. Export backup first with JSON export
  4. Upload smaller files
